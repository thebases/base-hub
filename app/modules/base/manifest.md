# Base

Core ERP foundation module for Base Hub.

This module provides the internal system metadata models and the first
foundational business models inspired by ERP `base`, including:

- `sys.module.module`
- `sys.model`
- `sys.model.field`
- `base.groups`
- `sys.model.access`
- `sys.rule`
- `base.partner.category`
- `res.partner`
- `res.company`
- `base.users`
- `sys.config_param`

It is the kernel module that seeds the modular-monolith runtime.
