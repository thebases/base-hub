## Get System Config

`GET /base/system-config` is not implemented in Base HUB (it returns `404`). Base HUB has no single "runtime config" document. Read settings one by one from the `sys.config_param` model instead.

### Before you start

You need a bearer token whose user may read `sys.config_param`. Only give this access to trusted admins: the rows are not masked and can contain secrets such as keys and passwords.

### Request

```http
POST /rpc/sys.config_param/search_read
Authorization: Bearer <token>
Content-Type: application/json
```

Each setting is a row. `name` is a dot-path key such as `attachment.max_size_mb`. `value` is any JSON value. Send these in `kwargs`:

| Name | Type | Required | What it means |
| --- | --- | --- | --- |
| `domain` | array | No | Filter, e.g. `[["name","ilike","edc."]]` finds names containing `edc.`. |
| `fields` | string[] | No | Columns to return, e.g. `["name","value"]`. |
| `limit` / `offset` | integer | No | Paging, e.g. `20` and `0`. |

### Example

```bash
curl -X POST "$BASE_URL/rpc/sys.config_param/search_read" \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"kwargs":{"domain":[["name","ilike","edc."]],"fields":["name","value"]}}'
```

### Response

```json
{
  "id": "111020261535481234570001",
  "result": [
    { "name": "edc.device_http_auth", "value": "public" }
  ]
}
```

| Field | What it means |
| --- | --- |
| `id` | Request id (yours, or generated by the server). |
| `result` | The matching settings. |
| `result[].name` | The setting key. |
| `result[].value` | The setting value (string, number, boolean, array...). |

### Errors

Errors use the standard format described in the API guide (see "Response" → "Errors").

| HTTP | `error.code` | What it means | What you should do |
| --- | --- | --- | --- |
| `401` | `-32001` | Missing or invalid token. | Get a new token. |
| `403` | `-32003` | The user has no access to `sys.config_param`. | Ask an admin for access. |
| `404` | `-32601` | You called `GET /base/system-config`, which does not exist. | Use the RPC call above. |

### Good to know

- Never log or share the full response: it can include secrets.
- The EDC module reads, among others, `edc.device_http_auth` (`public` or `token`) and `edc.provisioning.activation_code_ttl_minutes`. Provisioning on/off and the encryption key are `app.deviceProvisioningEnable` and `app.encryptKey`. Environment variables are not read.
- For service health and dependency state use `GET /health/detail` (see "Get Feature Flags").
